Run CatalogMusic.py with these args to look at the file system

relative filenames are often mapped into the folder specified by --outputdir

if you specify filesystem input files with --media_files_dirs and the output directory exists,
    it is removed to make things clean
Current args files are set up to with the output directory as C:\dev\CatalogMusic\iTunesData\Thunder\fileSystem\songs
log files are put in the logs directory inside the output directory
it will run through all the music files it finds listed in the directories specified by --media_files_dirs
json files are then written to the songs directory including
    Albums, Artists folder with individual json files for each album or artist
    Artists_list.json, Albums_list.json contain the entire library organized by artist or album in a single file
    Albums_Artists_flat & Artists_Albums_flat contain a single file per album organized as the name implies
    iTunesSongs.json - this file contains flat list with a single entry for each song file found

Run CatalogMusic.py with these args to look at the iTunes file
Be sure the iTunes file has been freshly exported so it is current

To have iTunes export its data to an xml file:
    To share your iTunes library's XML file with other applications on Windows,
        open iTunes preferences,
        go to the Advanced tab,
        and check the box for "Share iTunes Library XML with other applications"
   This will write the xml file on start and exit of iTunes. The file it writes is:
        "C:\Users\bruce\Music\iTunes\iTunes Music Library.xml"
   If you want to control when your xml file gets updated, you can use the menu,
        "File\Library\Export Library" and save it to a seperate file. I am currently saving to
        "C:\Users\bruce\Music\iTunes\Library.xml"
